# Mesto: интерактивная галерея фотографий


**Mesto** - это одностраничное приложение для обмена фотографиями мест с возможностью редактирования профиля, добавления/удаления карточек и просмотра изображений.

## 🚀 Функционал

✔️ Редактирование профиля пользователя (имя, описание)  
✔️ Добавление новых карточек с фотографиями мест  
✔️ Просмотр фотографий в полноэкранном режиме  
✔️ Лайки карточек  
✔️ Удаление карточек  
✔️ Валидация форм
